Les sources, la bande-son WAV, les exports, les captures de vérification et leurs rapports sont conservés tels qu’à l’approbation. Les mentions V11 dans ces documents désignent le numéro de travail de cette V3 finale.

`inputs/` fige les ressources et polices employées, le CSS de l’identité, les deux documents utilisés pour reconstruire la chronologie et la portion vidéo reprise sans réencodage. Les sources gardent leurs chemins de travail historiques : pour une éventuelle régénération, utiliser une copie séparée et rétablir ces entrées aux emplacements attendus, ou utiliser le master vidéo conservé dans `exports/`. Ne pas modifier l’archive approuvée.

`archive-manifest.json` répertorie les tailles et empreintes SHA-256 de tous les fichiers, hors manifeste lui-même. Les versions de travail ont été supprimées à la demande de l’utilisateur ; seules les archives V1, V2 et V3 sont conservées.
